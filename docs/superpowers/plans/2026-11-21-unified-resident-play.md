# 千灯纪居民与玩家模式整合计划

**目标**　保留一个 `minecraft_autonomous` 安装包，在同一插件中提供车万女仆／Numen 和普通玩家两条入口。

**范围**　沿用居民 0.3.2 的官网授权、角色选择和回合协议。保留玩家原配置及 MC 核心。居民模式使用本机角色，通过服务端执行已提供的能力。用户显式开始后才启用对应控制。角色迁移使用官网重新授权和原身体 UUID。

## 接入与生命周期

- [x] 从居民 0.3.2 的已验收代码移植 N.E.K.O. 适配器，并保留 MIT 许可。授权和保存绑定只写新插件自己的目录。
- [x] 用 `resident_start`、`resident_stop` 控制居民轮询和动态工具注册。开始时核对授权，停止时等已发出的回复返回，清理本机工具。
- [x] 沿用玩家锁和原状态检查，在玩家运行、清理或准备启动时拒绝双开。公开玩家入口保持原参数契约。
- [x] 在 `tests/test_resident_mode.py` 用真实 SDK 和替代传输验证默认停止、已有角色 UUID、权限、一次原生回复、模式互斥和停止。

## 界面与交付

- [x] 在主面板提供「连接车万女仆」入口，专用面板展示角色、授权、准备状态和桌面控制。旧玩家路径保留。
- [x] 更新版本和说明。运行插件 pytest、Node 回归、固定 Ruff 及官方 N.E.K.O. 检查，检查包内面板、入口和核心清单。
- 源码按仓库流程核对远端后普通推送。面向用户的发布另按官方安装与实服验收处理。

本轮验证使用真实 N.E.K.O. SDK 和隔离存储。居民回合及官网授权使用测试替身。独立安装、现有「悠怡 → 结衣」迁移及游戏内实际送达留待正式验收。2026-11-21 核对主仓上游 `e7c8f4b11d4d45455d1f1d46cdd096fedc4d7603`。本次居民行为采用已验收的 `bf913815`，玩家框架、核心、玩法模块与观战继续使用 0.6.157 的固定版本。

官方构建的 Windows 候选通过包内校验和隔离导入。完整 ZIP 校验全部 CRC，包含同一插件，41981 个运行资源成员的路径、长度和 CRC 与 0.6.157 精简包一致。
