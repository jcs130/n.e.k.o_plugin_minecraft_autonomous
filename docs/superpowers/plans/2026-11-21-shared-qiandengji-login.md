# 千灯纪统一登录与玩法选择

**目标**　居民和 Mineflayer 共用一次官网登录和六位数字授权，通过插件选择玩法。

**实现**　现有居民官网页面增加明确的玩家账号准备授权。官网将它限定为同一网站账号、同一插件申请和同一玩家身份。插件保存独立角色绑定和原游戏登录资料，复用原有玩家准备与断点恢复。

- 在官网 `resident-turns.mjs` 与 `neko-plugin-links.mjs` 接通共享授权，保持老版居民和猫娘计划关联协议。
- 在插件账号页统一授权和玩法说明。居民面板使用同一状态，已有玩家登录、自有服务器和原角色保留原路径。
- 验证一次授权可准备玩家账号并绑定原居民、切换不自动创建／进服、已有账号优先以及响应丢失后的原申请恢复。
- 运行官网及插件隔离回归，核对分发包和普通源码推送。正式网站上线与实服验收分别留证。
