# 原版 1.21.1 现场记录（2026-10-13）

时间均为北京时间。用户授权建立新的原版测试服；旧无人值守和旧游戏插件保持停用。
这是一组基础接入验收，尚不能证明长期自主生存或复杂目标可靠完成。

## 独立部署

- 原版 Java 1.21.1、Java 21，新存档，仅监听 `127.0.0.1:25571`。
  离线认证只用于本机测试；服务器、启动器及存档在独立私有部署目录，不进入插件仓库。
- 官方 server JAR SHA1：`59353fb40c36d304f2035d51e7d6e6baa98dc05c`。
  来源：[Mojang 官方清单](https://launchermeta.mojang.com/mc/game/version_manifest_v2.json)。
- Minecraft 客户端 `ag_NEKO` 使用已校验的 `7889ce2` 派生 headless 核心。
  规划模型显式配置为本机现有 Qwen 服务；没有切换权重或显卡。
- Neko 经官方开发目录注册接入同一会话账本，使用 external 模式读取状态、投递目标。
  SDK 和宿主源码未修改；Neko 插件重载时，独立身体仍保持连接。

## 实跑推动的修复

1. 将核心指南中的 `mc_scout` 纳入直接工具目录，并保留默认 append 队列语义。
2. 修正固定提示较大时所有工具回执被淘汰的问题，保留最近完整调用与错误反馈。
3. 常驻目标的错误完成报告返回可纠正回执，不再直接断开游戏。
4. 完整保留模型返回及被拒绝响应。截断响应在发出动作前拒绝，允许两次有退避的恢复；
   连续三次失败仍停止。原生结果未知的动作继续禁止重放。
5. 增加公共 Neko LLM 工具，紧凑读状态、分页读事实、投递意图与显式停止。
