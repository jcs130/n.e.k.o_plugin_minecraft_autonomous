# 调用纠错不阻塞整个 Agent

0.6.127 固定消费共享 `agent-mc-autonomy` 框架 0.2.124；身体核心仍为
rc.124，模型、人格、记忆、账号和服务器扩展继续由原配置提供。

原来的共享控制器把重复参数错误写入全局 `planner_retry_at`，
累计后最多等待 300 秒；明确未派发的重复调用及无效果恢复还会加入 30 秒全局等待。
现在保留同一错误操作的拒收证据和防重投，模型可在正常决策频率下查帮助、
提交修正参数或选择别的操作。重复计数不等于已执行动作次数。

每条纠错链仍有界，第一次已知 JSON 语法错误保留一次即时纠错机会；
后续回到配置的正常决策节奏，不发起无界即时重试。不会替模型修参、
伪造执行、取消现有工作、清空错误账本或自动完成目标。

`planner_correction.scope=call`、`global_backoff_added=false` 表示该问题只影响
调用本身。独立存在的服务端重试期限保留；`planner_retry_seconds` 继续如实
显示该剩余期限。这不是取消真实限流处理或未知执行保护。

实现与独立打包验证位于共享仓库
[调用纠错契约](https://github.com/jcs130/minecraft-ai-friend/blob/main/packages/agent-mc-autonomy/docs/call-correction.md)。
插件仅固定消费该来源，没有复制另一套自治策略。源码、打包、现场加载与游玩效果
分别验收；回归通过不等于所有模型都会一次生成正确参数。

0.2.124 补齐两处无动作回执：已经满足到达条件、死亡教训内容未变化。
它们只结束当前工具链，不再累加全局等待或纯文本无行动计数；下一次可按
配置的正常决策间隔选择其他工作。原回执、去重和目标未完成的含义保留。
纯文本没有工具调用时的有界空闲复查策略，以及真实服务故障重试仍保留。
本次源码同步不代表已重载现役插件，也不是市场版本发布。
