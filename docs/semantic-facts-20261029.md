# Producer semantic state comparison

0.6.123 consumes canonical autonomy 0.2.120 from
`5349b8f57cb67e5ccc3ca2f086aca87e0cf74209`, and the separately built core
rc.121 from `4556b9ec06d6e63d9a44ec51a054b0970111d3de`.

The core declares a semantic digest for recovery facts. Sampling time remains in
raw text and original evidence, but does not alone invalidate a previously
answered read. Position, health, food, life identity and stock still participate.
Undeclared RPG and combat facts retain conservative text comparison. The adapter
does not implement another cache or game policy. Scope, expiry, unknown effects
and native pending work remain the canonical framework's responsibility.

This is a source candidate, not a Market/npm release or proof of better live
gameplay. Install the matching verified core into a separate directory before
changing an existing backend selection; retain the original goal, account and
character configuration at a settled native boundary. Public runtime download
metadata is not replaced with an unpublished artifact URL by this change.
