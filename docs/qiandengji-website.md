# 千灯纪网站邀请接入

0.6.93 开发版按 [join](https://mc.kangqiang.site/join) 与 [Agent API](https://mc.kangqiang.site/agent-api.html) 的 Skill 1.1.0 接入。网站流程是显式可选账户扩展，原生身体仍为当前固定的 Agent MC World；不运行 Skill 包里的旧核心或另起 MCP，不替换模型、人设或记忆。

已有游戏角色继续原账号、密码文件和原启动配置。邀请只能创建未使用的新角色，不能认领旧角色；旧角色绑定网站需要原游戏角色完成官方验证。面板的「千灯纪公网」仍只填连接草稿，不注册或自动连接。

## 新邀请角色

1. 在网站连接中心选择「邀请自己的 Agent」，复制专属邀请链接。不要发送到聊天或公开分享。
2. 在插件面板选择「千灯纪公网」，展开「用官网邀请创建新 Agent」，填写未使用的角色名并将链接粘贴到专属邀请框。角色名必须 `ag_` 开头，仅字母、数字、下划线，总长最多 16 位。
3. 点击「创建此 Agent 账号」。插件在当前用户私有目录中自动准备文件；固定官网工具在 HTTP 请求前保存独立身份、游戏密码及原请求编号。无需填写文件路径、编辑 JSON 或运行命令。
4. 点击「查询已保存账号」，按状态激活，再「重新核对并接入」。`pending` / `unknown` 继续查询同一个身份。关闭面板后仍保留原请求；重复创建会沿用已保存的请求查询，不另建身份。已有身份 JSON 的用户也可直接点「选择已有 Agent 身份文件」和「接入所选账号」。
5. 只有 `gameAccountCreated=true`、`state=ready`、同一角色、官方地址和 Java 1.21.1 均匹配时，才允许导入连接。嵌入式模式需先停止并等原生动作对账；导入只保存连接和私有文件路径，不自动开玩。再次点击开始时会重新查询 ready，然后由原生连接等待 `MC_AUTH_SUCCESS` / 授权回执和真实 PLAY 世界。游戏端拒绝、认证未确认或 API 异常均不证明入服成功。
6. 实际入服后通过唯一原生队列读取自己状态，执行 `/mycli help`、`/mycli status`，再由角色选择附近行动。发送、受理与真实完成分开核对；重连不重放未知动作。

外部模式的面板只观察独立执行器，不切换它的身份或写入其启动配置。新邀请身份需由所属启动器在连接前执行相同官方 status/ready 核对；本插件拒绝在外部模式导入，以免产生只检查面板、实际身体绕过核对的配置。

## 私有文件与官方工具

身份文件含 `clientSecret`、API session、独立 `gamePassword`，只保存在用户私有目录中，不能提交 Git、加入插件包、输出给模型或同步到公开目录。POSIX 使用 0600 文件和 0700 目录；Windows 放在仅本人有权访问的用户数据目录。面板仅显示状态、角色名及公开服务器信息。

通过文件选择器接入时，身份内容只发送给当前 Neko 运行机器并在该机器私有保存，不进入普通配置或面板回显。旧版路径入口保留在高级折叠项；普通安装无需使用它。账号接入不启动游戏，选好模型后仍由本人明确点击「开始自主游玩」。

官网工具原件位于 `assets/server-extensions/qiandengji/access/agent-register.mjs`，SHA256 为 `cfa9733c093a27093100b3c08b21de0727af24f486561a07bf5a7868d49ca5cd`。来源和 MIT 许可同目录保存。只有显式操作才运行它；插件导入、面板刷新不会联网注册或激活。也可在本机使用 Node 调用它的 `help`、`status --identity-file <私有绝对路径>` 等官方命令，凭据正文不出现在参数中。

导入生成的私有 `login.json` 只引用独立密码文件，通过现有核心的 `loginConfigFile` 精确匹配服务器和角色。API `qda_` 令牌不是游戏密码，不会被发入游戏。导入不会覆写冲突密码或已有身份。清空可选 `[qiandengji].identity_file` 仅用于明确改回原账号接入；不要靠清空它绕过未完成的新账号核对。

也可以在“服务器登录密码”保存该原账号的密码；插件自己的按服务器和昵称隔离的登录文件受同一 ready 核对保护，Windows 使用 DPAPI。启动失败会区分身份文件、连接、登录文件和网站状态问题；`pending/unknown` 仍不启动、不重复注册。普通已有游戏账号只需连接与 `/login` 密码，不需要伪造或新建邀请身份。

连接、账号与模型首次配置完成后，点击“开始自主游玩”即可使用默认自主生活目标和当前猫娘解说，无需向猫娘再发送一条聊天指令。插件安装、升级和页面刷新不会自动进入游戏。

此开发更新不等于公开 Release/Market 发布，也不证明长输入超时、长期生存或网站新身份的实服激活已经验收；后者需要真实专属邀请及完整官方回执。
